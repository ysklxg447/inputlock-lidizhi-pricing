## 到手价怎么算，哪一步能看到最终数字

会员价可能已经含在商品页显示的价格里，你看到的标价未必是原价，折扣码是在这个数字基础上再打。积分是下单之后返到账户、下次消费才能用的东西，不能抵扣这一单，算到手价的时候别把它减掉，否则你心里的预期价会比结算页低一截。

**「终身」的责任方是开发者。** 商店只负责转述官方信息。哪天开发商改了授权政策或者停止更新，商店不承担赔偿。把「终身版」理解成「当前版本可以长期用」，比理解成「永久免费升级」稳妥得多。

**授权不能共享或转售。** 购买须知明确禁止把商品共享、转售给第三方，违规后果自己承担。多人合买这种事，别在这类商品上做。

**买前先试用。** 商店自己写了，大部分商品支持买前试用，建议先下载安装、充分体验再决定。这是唯一能对冲「不退不换」的办法，别省这一步。
